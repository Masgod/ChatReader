# Release 0.3.0 Hardening Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 0.3.0 (`!random`, `!hero`, Twitch chat replies, Touch UI) only after the parts that so far passed unit tests alone have been run against real Twitch, OBS and a built package.

**Architecture:** No new features. Verify, fix what verification finds (each fix test-first), close the known risks, refresh the docs, build and publish. Tasks 1-3 need the owner's Twitch account and OBS; everything else is code work.

**Tech Stack:** Python 3.11+/uv, FastAPI, pytest (`uv run pytest -q -m "not slow"`), PyInstaller (`packaging/build.py`).

**Spec:** none. Source of truth is the work already merged on `main` (`ad8c75c`) and `docs/STATUS.md`.

## Global Constraints

- No push, tag or GitHub release without the owner's explicit yes in chat.
- Valve hero art stays in `%APPDATA%\ChatReader\themes\deadlock`, never in git.
- Every behaviour fix starts with a failing test.
- The unrelated untracked `docs/superpowers/plans/2026-10-20-languages.md` and `specs/2026-10-20-languages-design.md` are not part of this release; leave them alone.

## Review Focus

- Twitch token expired or revoked while the app runs: replies stop silently, the app must keep reading chat.
- Client ID saved but no account connected: `!hero` must still work with no reply.
- Touch pages on a screen under 480 px: a section that opens blank is a regression (happened once).
- A built `.exe` missing a new static file (`touchnav.js` was added after the last build).
- Restart while a reply or a save is in flight.

## Deferred minors

Recovered from the earlier review notes (Task 5, Step 1). None blocks the release; none was fixed in 0.3.

- Config: `load_config` does not type-check values; `save_config` does not create the parent folder; YouTube URL regex `v=` lacks a word boundary.
- Config save: `make_toggle` reads the config outside the lock, so a toggle can undo a concurrent save.
- Settings page: first-run voice dropdowns need a reload; the page stays empty if the first `/api/config` fails; the header says idle while YouTube is still waiting; the dock's save shows no error when the server is down.
- Player: a skip can race and play one stale sentence (microsecond window); pause does not stop the remaining sentences of the current message; an overlay disconnect mid-message drops the rest of it; no outcome event for items left at shutdown.
- Overlay hub: a slow client is dropped without closing its socket; the ninth-client limit is racy under simultaneous connects; one slow client can delay the voice up to 1 s.
- Filters: a long laugh in Portuguese (10+ identical characters) is dropped as spam; the history key ignores the platform and is case-sensitive.
- Startup shortcut: a refused registry write can still delete the old shortcut; the Run command breaks for a drive-root or relative `--home`; autostart is not reconciled at boot if the config was copied with `start_with_windows=true`.
- YouTube: the resolver is silent behind the consent wall (SOCS cookie).
